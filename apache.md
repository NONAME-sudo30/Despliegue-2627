## INSTALACIÓN APACHE EN VPS
Apache2 es un servidor web de código abierto que permite publicar páginas y aplicaciones en Internet o en una red local. 

Recibe las peticiones de los navegadores y entrega el contenido solicitado, como páginas HTML, imágenes o archivos.

Apache HTTP Server (o simplemente Apache) es uno de los servidores web más utilizados del mundo.

Su función es recibir las peticiones de los usuarios desde un navegador y enviarles las páginas web correspondientes.
